Copie os arquivos `.lua` desta pasta para a instalação do editor:

```text

```

Reinicie o editor. O script aparece no menu **Scripts**.

## global_idle_validate.lua

Valida uma área fixa de **21 × 13 SQMs** no andar indicado. Informe as coordenadas do canto superior esquerdo. O resultado aparece no console de scripts do RME.

O script é somente leitura: não muda tiles, itens ou o `.otbm`.
